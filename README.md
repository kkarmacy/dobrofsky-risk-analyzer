# Dobrofsky Risk Analyzer

A research-oriented financial risk analysis platform designed to separate data normalization, financial ratios, the Dobrofsky scoring methodology, explainability, stress testing, historical analysis, and benchmarking.

## Roadmap

1. Financial statement normalization and validation
2. Independent Dobrofsky scoring engine
3. Risk decomposition and explainability
4. Historical risk evolution and early-warning indicators
5. Stress testing and sensitivity analysis
6. Backtesting and benchmarking against established financial distress models
7. Web application and API

> Important: risk outputs are analytical estimates, not guarantees of default, bankruptcy, solvency, investment performance, or future outcomes. Model validation and documented backtesting are required before predictive claims are made.
